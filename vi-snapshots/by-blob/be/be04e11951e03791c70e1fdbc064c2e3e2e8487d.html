Actor Framework.lvlib:Stop Msg.lvclass:Send Normal Stop.vi

<p>(<strong>Filename</strong>: <span class="dnl">Actor Framework.lvlib:Stop Msg.lvclass:Send Normal Stop.vi</span>)</p>

<p>Sends a Stop message to an actor, triggering the actor to run its Stop Core method. This message has normal priority, meaning the actor will process this message after processing high- or normal-priority messages that are in the queue already.</p>
