Actor Framework.lvlib:Message.lvclass:Drop Message Core.vi

<p>(<strong>Filename</strong>: <span class="dnl">Actor Framework.lvlib:Message.lvclass:Drop Message Core.vi</span>)</p>

<p>Defines what a message does if it is in the message queue when the queue is released. At this point, the actor has shut down, so it will never process the message.</p>

<p>By default, this method does nothing. A child class may override it to define behavior. National Instruments provides the Reply Msg class to override this method. This class releases its internal queue, which causes any caller of the <a href="nihelplauncher://docs/csh?context=lvcore_lvcomm_af_send_and_wait">Send Message and Wait For Response</a> method to stop waiting and return an error.</p>
