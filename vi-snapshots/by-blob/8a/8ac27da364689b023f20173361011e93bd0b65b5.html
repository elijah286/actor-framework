Actor Framework.lvlib:Time-Delayed Send Message.vi

<p>Waits for the specified amount of time and then sends a message to an actor a specified number of times.</p>

Connector Pane

Front Panel

Controls and Indicators

 Message Enqueuer

<strong>Message Enqueuer</strong> specifies the reference needed to send messages to the actor.

Message

<strong>Message</strong> specifies the message to send.

Milliseconds To Wait

<strong>Milliseconds To Wait</strong> specifies the time, in milliseconds, this VI waits before sending the <strong>Message</strong>.

# Copies (0 = infinite repeat)

<strong># Copies</strong> specifies the number of times this VI sends the <strong>Message</strong>. The default is 0, which specifies to send the message an infinite number of times. Use the <strong>Delivery Notifier</strong> to stop sending the message.

error in (no error)

<strong>error in</strong> describes error conditions that occur before this node runs. This input provides <a href="nihelplauncher://docs/csh?context=lvcore_lvconcepts_using_standard_error_in">standard error in</a> functionality.

    		status

    <strong>status</strong> is TRUE (X) if an error occurred before this node ran or FALSE (checkmark) to indicate a warning or that no error occurred before this node ran. The default is FALSE.

    		code

    <strong>code</strong> is the error or warning code. The default is 0.

    		source

    <strong>source</strong> specifies the origin of the error or warning and is, in most cases, the name of the node that produced the error or warning. The default is an empty string.

Message Priority (Normal)

<strong>Message Priority</strong> specifies the placement of the <strong>Message</strong> in the message queue. This placement determines when the actor will process the message.

Delivery Notifier

<strong>Delivery Notifier</strong> returns a notifier refnum you can use to preempt or reschedule the message delivery. This output also contains an enum of a typedef with valid values to send to the notifier.

error out

<strong>error out</strong> contains error information. This output provides <a href="nihelplauncher://docs/csh?context=lvcore_lvconcepts_using_standard_error_out">standard error out</a> functionality.

    		status

    <strong>status</strong> is TRUE (X) if an error occurred or FALSE (checkmark) to indicate a warning or that no error occurred.

    		code

    <strong>code</strong> is the error or warning code.

    		source

    <strong>source</strong> describes the origin of the error or warning and is, in most cases, the name of the node that produced the error or warning.
