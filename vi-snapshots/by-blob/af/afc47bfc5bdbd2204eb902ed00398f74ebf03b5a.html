Actor Framework.lvlib:Message Dequeuer.lvclass:Equals Not A Refnum.vi

<p>(<strong>Filename</strong>: <span class="dnl">Actor Framework.lvlib:Message Dequeuer.lvclass:Equals Not A Refnum.vi</span>)</p>

<p>Checks whether a message dequeuer reference is equal to Not a Refnum. Unlike the <a href="nihelplauncher://docs/csh?context=lvcore_glang_not_a_number_path_refnum">Not a Number/Path/Refnum?</a> function, this function does not check whether a non-zero reference still is valid. Refer to the detailed help for more information.</p>

Connector Pane

Front Panel

Controls and Indicators

 Message Dequeuer

<strong>Message Dequeuer</strong> specifies a message dequeuer to check.

Not a refnum?

<p><strong>Not a refnum?</strong> returns TRUE if <strong>Message Dequeuer</strong> is equal to Not a Refnum, in which case you should not attempt to use this reference to read a message.</p>

<p>This output returns FALSE in all other situations, including when <strong>Message Dequeuer</strong> is a non-zero refnum that has been released already. In these situations, send the message and then check for an error on that operation.</p>
