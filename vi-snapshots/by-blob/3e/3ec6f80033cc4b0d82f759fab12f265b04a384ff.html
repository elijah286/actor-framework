Actor with Nesteds.lvlib:Actor with Nesteds.lvclass:Handle Last Ack Core.vi

<p>(<strong>Filename</strong>: <span class="dnl">Actor Framework.lvlib:Actor.lvclass:Handle Last Ack Core.vi</span>)</p>

<p>Defines how the caller actor responds to the Last Ack message from a nested actor. The Last Ack message is the final message a nested actor sends to its caller before it shuts down. The message contains information about the final state of the nested actor.</p>

<p>By default, this method does nothing except return any error the nested actor sent. A descendant class may override this method to define behavior.</p>
