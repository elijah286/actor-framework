Reply Msg.lvclass:Do Core.vi

<p>(<strong>Filename</strong>: <span class="dnl">Actor Framework.lvlib:Reply Msg.lvclass:Do Core.vi</span>)</p>

<p>Defines what an actor does when it receives <strong>Reply Message</strong>. This method also defines the <strong>Reply</strong> that is returned to the actor that sent <strong>Reply Message</strong>.</p>

<p>By default, this method does nothing, and <strong>Reply</strong> is the ancestor Message class. A child class must override this method to define behavior and specify a child of the Message class to return in the <strong>Reply</strong> output.</p>
