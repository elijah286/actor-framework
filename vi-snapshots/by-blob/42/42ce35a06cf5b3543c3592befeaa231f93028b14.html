Actor Framework.lvlib:Stop Msg.lvclass:Send Normal or Emergency Stop.vi

<p>(<strong>Filename</strong>: <span class="dnl">Actor Framework.lvlib:Stop Msg.lvclass:Send Normal or Emergency Stop.vi</span>)</p>

<p>Sends a Stop message to an actor. The priority of this message is determined by the value of the <strong>final error code</strong> input. If this input is <span class="Monospace">0</span>, this VI sends the message with normal priority; otherwise, it sends the message with critical priority.</p>

<strong>final error code</strong> specifies the error code that determines whether this VI sends a normal- or critical-priority message. A value of <span class="Monospace">0</span> sends a normal-priority message. Any other value sends a critical-priority message.
