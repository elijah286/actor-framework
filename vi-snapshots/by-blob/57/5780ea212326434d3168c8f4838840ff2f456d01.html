State Actor.lvclass:Change State.vi

This method defines state transitions; use it to construct the specific state transitions of your State Pattern Actor.

The method takes the current state and the next state as inputs. It invokes Exit.vi on the current state. It then invokes Substitute Actor.vi to transfer data from the current state to the next state. Finally, it invokes Entry.vi on the new state, and returns that state as the current state.
