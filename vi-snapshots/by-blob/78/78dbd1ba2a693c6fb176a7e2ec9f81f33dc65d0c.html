Actor with Nesteds.lvlib:Stop Nested Actors Msg.lvclass:Send Stop Nested Actors.vi

<p>(<strong>Filename</strong>: <span class="dnl">Actor Framework.lvlib:Report Error Msg.lvclass:Send Error Report.vi</span>)</p>

<p>Use this VI to send an error to an actor. The error will be handled by the Handle Error VI of the actor. If the error is not handled there, it will cause the actor to stop running.</p>

Front Panel

Controls and Indicators

 error in (no error)

<strong>error in</strong> describes error conditions that occur before this node runs. This input provides <a href="nihelplauncher://docs/csh?context=lvcore_lvconcepts_using_standard_error_in">standard error in</a> functionality.

    		status

    <strong>status</strong> is TRUE (X) if an error occurred before this node ran or FALSE (checkmark) to indicate a warning or that no error occurred before this node ran. The default is FALSE.

    		code

    <strong>code</strong> is the error or warning code. The default is 0.

    		source

    <strong>source</strong> specifies the origin of the error or warning and is, in most cases, the name of the node that produced the error or warning. The default is an empty string.

Message Enqueuer

<strong>Message Enqueuer</strong> specifies a message enqueuer to check.

Message Priority (Normal)

<strong>Message Priority</strong> specifies the placement of the messages in the message queue, which determines when the actor will process the messages.

error out

<strong>error out</strong> contains error information. This output provides <a href="nihelplauncher://docs/csh?context=lvcore_lvconcepts_using_standard_error_out">standard error out</a> functionality.

    		status

    <strong>status</strong> is TRUE (X) if an error occurred or FALSE (checkmark) to indicate a warning or that no error occurred.

    		code

    <strong>code</strong> is the error or warning code.

    		source

    <strong>source</strong> describes the origin of the error or warning and is, in most cases, the name of the node that produced the error or warning.

Message Enqueuer out

<strong>Message Enqueuer</strong> specifies a message enqueuer to check.
