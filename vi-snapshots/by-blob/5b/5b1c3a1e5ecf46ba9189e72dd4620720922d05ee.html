Process States.lvlib:Running.lvclass:Exit.vi

This override sends a Stop Acquisition message to the Process Actor. It also sends a Log Event message to the UI, with the string containing "Exiting Running State", the average value of the data stream, and the total number of elements of the steam as its payload.
