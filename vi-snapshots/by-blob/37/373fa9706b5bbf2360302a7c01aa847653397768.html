Actor Framework.lvlib:Message Dequeuer.lvclass:Dequeue.vi

<p>(<strong>Filename</strong>: <span class="dnl">Actor Framework.lvlib:Message Dequeuer.lvclass:Dequeue.vi</span>)</p>

<p>Reads a message that a top-level actor sent to its caller. Use this VI to interact with non-actor code, not in a VI that belongs to an actor.</p>

Connector Pane

Front Panel

Controls and Indicators

 Message Dequeuer in

<strong>Message Dequeuer in</strong> specifies the reference needed to read messages from a top-level actor.

error in (no error)

<strong>error in</strong> describes error conditions that occur before this node runs. This input provides <a href="nihelplauncher://docs/csh?context=lvcore_lvconcepts_using_standard_error_in">standard error in</a> functionality.

    		status

    <strong>status</strong> is TRUE (X) if an error occurred before this node ran or FALSE (checkmark) to indicate a warning or that no error occurred before this node ran. The default is FALSE.

    		code

    <strong>code</strong> is the error or warning code. The default is 0.

    		source

    <strong>source</strong> specifies the origin of the error or warning and is, in most cases, the name of the node that produced the error or warning. The default is an empty string.

timeout in ms (-1)

<strong>timeout in ms</strong> specifies the time, in milliseconds, this VI has to read the message. The default is -1, which specifies no timeout.

Message Dequeuer out

<strong>Message Dequeuer out</strong> returns a duplicate of <strong>Message Dequeuer in</strong>.

Message

<strong>Message</strong> returns the message that was read from the queue. If <strong>timed out?</strong> returned TRUE, <strong>Message</strong> returns the default Message class.

error out

<strong>error out</strong> contains error information. This output provides <a href="nihelplauncher://docs/csh?context=lvcore_lvconcepts_using_standard_error_out">standard error out</a> functionality.

    		status

    <strong>status</strong> is TRUE (X) if an error occurred or FALSE (checkmark) to indicate a warning or that no error occurred.

    		code

    <strong>code</strong> is the error or warning code.

    		source

    <strong>source</strong> describes the origin of the error or warning and is, in most cases, the name of the node that produced the error or warning.

timed out?

<strong>timed out?</strong> returns TRUE if this VI was unable to read the message within the specified <strong>timeout in ms</strong> period. In this situation, <strong>message</strong> returns the default Message class.

priority

<strong>priority</strong> returns the priority level at which LabVIEW sent the message.
