Actor Framework.lvlib:Actor.lvclass:Send Launch Nested Actor Msg.vi

<p>(<strong>Filename</strong>: <span class="dnl">Actor Framework.lvlib:Actor.lvclass:Send Launch Nested Actor Msg.vi</span>)</p>

<p>This VI sends a message containing an actor to another actor. The actor receiving the message will launch the payload actor as a nested actor. Use this VI only to send a message from an actor to itself.</p>

Connector Pane

Front Panel

Controls and Indicators

 Nested Actor

<strong>Nested Actor</strong> is the initial state of the actor you want to launch.

Open Actor Core front panel? (F)

<p><strong>Open Actor Core front panel?</strong> specifies whether, on launching the actor, the front panel of the Actor Core method opens. The default is FALSE. The TRUE setting causes this VI to return an error in the run-time engine.</p>

<p>Set <strong>Open Actor Core front panel?</strong> to TRUE during code development so you can access the <strong>Abort</strong> button for the VI, which helps if you forget to stop an actor. To open the Actor Core front panel of an actor for purposes other than debugging, use the <a href="nihelplauncher://docs/csh?context=lvcore_lvprop_vi_open_front_panel">Front Panel:Open</a> method. You can also enable <strong>Show front panel when called</strong> on the <a href="nihelplauncher://docs/csh?context=lvcore_lvdialog_cust_window_appearance_db">Customize Window Appearance</a> dialog box to configure this VI to open the Actor Core front panel when you call the actor.</p>

Auto-stop? (T)

<strong>Auto-stop</strong> determines whether <strong>Nested Actor</strong> stops when the calling actor stops. The default value is TRUE. If you set the value of this input to FALSE, you must manually override the <a href="nihelplauncher://docs/csh?context=lvcore_lvcomm_af_stop_core">Stop Core VI</a> on the caller actor to specify stop behavior for <strong>Nested Actor</strong>.

Self Enqueuer in

<strong>Self Enqueuer in</strong> is the reference the actor uses to send messages to itself.

error in

<strong>error in</strong> describes error conditions that occur before this node runs. This input provides <a href="nihelplauncher://docs/csh?context=lvcore_lvconcepts_using_standard_error_in">standard error in</a> functionality.

    		status

    <strong>status</strong> is TRUE (X) if an error occurred before this node ran or FALSE (checkmark) to indicate a warning or that no error occurred before this node ran. The default is FALSE.

    		code

    <strong>code</strong> is the error or warning code. The default is 0.

    		source

    <strong>source</strong> specifies the origin of the error or warning and is, in most cases, the name of the node that produced the error or warning. The default is an empty string.

Message Priority (Normal)

<strong>Message Priority</strong> specifies the placement of the messages in the message queue, which determines when the actor will process the messages.

error out

<strong>error out</strong> contains error information. This output provides <a href="nihelplauncher://docs/csh?context=lvcore_lvconcepts_using_standard_error_out">standard error out</a> functionality.

    		status

    <strong>status</strong> is TRUE (X) if an error occurred or FALSE (checkmark) to indicate a warning or that no error occurred.

    		code

    <strong>code</strong> is the error or warning code.

    		source

    <strong>source</strong> describes the origin of the error or warning and is, in most cases, the name of the node that produced the error or warning.

Self Enqueuer out

<strong>Self Enqueuer out</strong> returns the reference the actor uses to send messages to itself.
